WBNHS - BSP | Template — PWA package

DEPLOYMENT
1. Upload the CONTENTS of this folder to the ROOT of your GitHub Pages repository.
2. Keep the templates folder and all its files in place.
3. Enable GitHub Pages from Settings > Pages > Deploy from branch > main > /(root).
4. Open the HTTPS Pages URL in Chrome and install the app.

PRELOADED TEMPLATES
The app seeds a built-in profile named “WBNHS–BSP Official Templates” on first launch.
Landscape template: templates/default-landscape.png (3750 × 1969)
Portrait template: templates/default-portrait.png (3375 × 4219)
Both files retain their PNG alpha transparency and are stored in IndexedDB during setup.

UPDATES
